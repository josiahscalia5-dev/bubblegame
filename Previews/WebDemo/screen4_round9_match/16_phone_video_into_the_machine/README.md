# Phone video: into the washing machine (recorded 5 November 2026, about 21:00 UTC; sent to the user 6 November)

`pixel7_preview_into_the_machine_10s.mp4`: 10 s of real gameplay on a Pixel 7-sized screen (412 x 839 CSS px at 2x, so
824 x 1678), `?s3=match`, recorded with `scripts/record_phone.cjs` (a phone copy of `WebDemo/tools/screen3/record_s3.cjs`):
the game is stepped at exactly 30 frames per game second and every frame captured, so the video plays at true game speed;
every input is a real pointer gesture on the stage (tap to start at 2.0 s, then left, right, jump and spin on the
recorder's fixed script). The game's random numbers are not seeded in this recorder, so it is not the same moment as the
seed-7 comparisons.

The build is the 20:45 preview (`15_phone_preview_2045utc/`): `edf84f5` plus both specialists' unfinished files at 20:44
UTC (Tunnel & Lighting's larger-character framing, sock tilt and walls; Water & VFX's foam follow-up). Not merged.

`frames_strip_1.0_2.4_3.0_3.6_4.4_5.5_7.0_9.0s.jpg`: stills at those times: Tap to Start, the slide, the rim, entering
the tunnel, inside it with coins, the gem and a sock collected. The hearts fall from 5 to 3 because the fixed script does
not dodge every hazard.
