Bubble Wash Kingdom - Giant Side Washing Machinery - Claudia Code Package

Model source: the user's uploaded Meshy 3D GLB; original is unchanged.
Original: approx 121.8 MiB; 3,572,718 triangles; 1,910,639 vertices.

Optimized versions:
- Balanced: 4.90 MiB; 135,862 triangles; 90,794 vertices; 1024px texture maps. Recommended first upload to Claudia.
- Medium: 8.06 MiB; 252,725 triangles; 157,406 vertices; 768px texture maps. If Balanced looks too faceted, use this.
- Small: 1.91 MiB; 49,259 triangles; 38,255 vertices; 512px texture maps. Strong detail loss; for import test only.
- HighQuality: 15.64 MiB; 513,457 triangles; 301,044 vertices; 1024px maps. If needed, available separately; not included in the smaller ZIP.

The models were reduced using geometry clustering, not full topology-preserving quadric decimation. Some thinning of the fine bristle surfaces, visible cracks and faceting can occur, particularly in the smallest versions; compare carefully inside the browser game before final approval. The texture files were reduced and recompressed.

Each GLB was successfully read by a glTF importer and rendered in a simple 3D preview. No runtime in Claudia's actual game has been tested in this session.

Use the accompanying Claudia import prompt. This new giant side machinery is a decorative assembly; it is not a replacement for the prior rotating brush.
