# Bubble Wash Kingdom — 4 Modular Decor GLBs for Claudia Code

The four Meshy original masters were inspected, simplified, textured, exported and re-opened successfully.

The 4 new models are decorative assets (water tower, gear, pipe, crown/trim), not replacements for your existing washing roller, castle, or washer tunnel.

Balanced = higher quality of geometry and textures; Small = lighter files, with visibly rougher details and occasional texture artifacts on small bolts/gems. Try Balanced first if Claudia accepts the file size, otherwise Small. These have NOT been tested inside the running browser game; previews are offline renders.

## File sizes
- Glowing Water Tower / Balanced: 6.74 MB, 95,000 triangles, 1024px texture
- Glowing Water Tower / Small: 2.01 MB, 25,000 triangles, 512px texture
- Blue-and-Gold Gear Wheel / Balanced: 6.24 MB, 74,999 triangles, 1024px texture
