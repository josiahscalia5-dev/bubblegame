PINK FLUFFY MASCOT — OPTIMIZED FOR CLAUDIA CODE
Original Meshy GLB was ~322.2 MiB, 7,885,056 triangles and 6,812,672 vertices.

Optimized 4MB ColorSafe: ~3.79 MiB, 137,111 triangles, 61,062 vertices (recommended for first upload).
Optimized 10MB ColorSafe: ~9.85 MiB, 369,132 triangles, 172,667 vertices (more detail).

Both open successfully as glTF/GLB. The source mesh was clustered to reduce geometry; original color textures were downsized. Physically based material set to unlit so the fur retains bright pink coloring without harsh dark shadowing in a basic viewer. Both are static meshes, not rigged or pre-animated. 2D concept is not a guaranteed match in 3D; in preview some facial detail is partially hidden by fur and should be inspected from a gameplay camera.

For gameplay motion, Claude Code must implement controller, camera, water, collision, swipes and animation separately. The GLB itself is a static textured model.
