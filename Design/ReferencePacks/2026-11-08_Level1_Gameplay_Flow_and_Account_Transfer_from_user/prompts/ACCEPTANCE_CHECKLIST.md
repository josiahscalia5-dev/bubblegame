# Bubble Wash Kingdom Level 1 — Pass / Fail Acceptance Checkpoints

This checklist is an implementation QA contract, not proof that corrections have already been made.

- [ ] **Correct repo and safe branch** — base SHA recorded, new agent branch isolated, no other session's uncommitted work overwritten.
- [ ] **Home** — 3D Tripo girl recognizable, pink mascot and washer staged like approved girl art, clean readable title/buttons/HUD.
- [ ] **Real girl motion** — eyelids and head, shoulders and arms move visibly; basket tips, separate socks/towels follow plausible arcs.
- [ ] **Real washer crossing** — mascot physically crosses hollow circular port; no teleport/frozen 2D cut; camera follows it into the water.
- [ ] **Classic Screen 4 visual** — original approved pink rear-view shape, saturated cobalt/turquoise water ON body, original washer silver/lavender/purple framing, real fluffy brushes, coins, socks, bubbles, camera. No white cushion/film.
- [ ] **Swimming** — world-distance advances; bob, steer, tilt and wake are synchronized; collectibles and obstacles pass in 3D and can be touched/missed.
- [ ] **Middle / branches** — both paths remain visibly watery within the same machine's structural language; no dry rails/ground path.
- [ ] **Castle approach** — remove/rework the current long dry-looking road; stay on animated blue water and in connected metallic washer tunnel/chamber.
- [ ] **Level Complete** — trigger while pink mascot is still physically supported by blue water; reward UI over the same wet world.
- [ ] **Performance** — report real mobile FPS, draw calls, GPU-heavy assets and resource optimization (no unverified performance claims).
- [ ] **Evidence** — original/current/new comparisons, full ~phone aspect run and short motion proof; tag each source clearly.
- [ ] **Safe merge** — source committed to independent feature branch, tests pass, PR available; Claude reviews and merges only after approval; final remote SHA verified.
